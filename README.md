# 📌 Overview

**Career Copilot** is an AI-powered career intelligence platform designed to help students and job seekers understand their current skills, identify gaps against target roles, and create a personalized path toward career readiness.

Instead of using separate tools for:

- Resume analysis
- Job matching
- Skill-gap analysis
- Career planning
- Interview preparation
- Learning guidance

Career Copilot brings these workflows together into a single intelligent platform.

The system analyzes a user's resume and target job requirements, identifies relevant skills and missing capabilities, generates a personalized roadmap, supports interview preparation, and provides conversational AI career guidance.

---

# 🎯 Problem

Students and job seekers often face several challenges while preparing for placements or jobs:

- They don't know whether their resume is strong enough.
- They don't know which skills are missing for a target role.
- They struggle to prioritize what to learn first.
- Job descriptions contain many requirements that are difficult to interpret.
- Interview preparation is often disconnected from their actual skill profile.
- Generic career advice doesn't account for the user's current abilities.
- Learning resources are often consumed without a clear career objective.

The result is a common question:

> **"What exactly should I do next to become job-ready?"**

Career Copilot is designed around answering that question.

⚙️ Getting Started
Prerequisites

Make sure the following are installed:

Python 3.14+
Node.js
npm
MySQL
Git
Ollama
1️⃣ Clone the Repository
git clone https://github.com/YOUR_USERNAME/career-copilot.git
cd career-copilot

2️⃣ Create Python Virtual Environment

On Windows:
python -m venv venv

Activate it:
.\venv\Scripts\Activate.ps1

3️⃣ Install Backend Dependencies
pip install -r requirements.txt

4️⃣ Configure MySQL

Create the database:

CREATE DATABASE career_copilot;

Create a .env file in the project root:

DATABASE_URL=mysql+pymysql://USERNAME:PASSWORD@localhost/career_copilot

⚠️ Never commit .env to GitHub.

5️⃣ Install Ollama

Download Ollama:
https://ollama.com/
Pull the required model:
ollama pull qwen3:4b
Verify:
ollama list

Expected model:
qwen3:4b

6️⃣ Start the Backend

From the project root:
python -m uvicorn backend.app.main:app --reload --port 8000

Backend:
http://127.0.0.1:8000

Swagger API documentation:
http://127.0.0.1:8000/docs


7️⃣ Install Frontend Dependencies

Open a new terminal:
cd frontend
npm install

8️⃣ Start the Frontend
npm run dev

Frontend:
http://localhost:8080

🧠 Engineering Decisions
Why FastAPI?

FastAPI provides:

Automatic API documentation
Type-safe request validation
Dependency injection
High-performance API development
Strong integration with Python-based AI workflows
Why MySQL?

MySQL provides a reliable relational database structure for storing:

User accounts
Resume information
Job descriptions
Career roadmaps
Interview sessions
Interview questions
Why Ollama?

Ollama allows the application to run language models locally.

This reduces dependency on paid external LLM APIs during development and allows AI functionality to run on the developer's own machine.

Why Qwen3 4B?

Qwen3 4B provides a relatively lightweight local language model suitable for development workflows where structured AI responses and local inference are useful.

🎓 Project Purpose

Career Copilot was created to solve a practical problem faced by many students and early-career developers:
"I want a job, but I don't know exactly what I should learn, what I'm missing, or what I should do next."

The project combines AI, backend engineering, databases, frontend development, and career intelligence into one practical application.

⭐ Why Career Copilot?

Career Copilot is designed around a simple idea:
Don't just tell users what they are missing — help them understand what to do next.
Traditional career tools often operate independently:

Resume Analyzer
       +
Job Portal
       +
Learning Platform
       +
Interview Platform
       +
Career Advice

Career Copilot connects these workflows:

Resume
   ↓
Skills
   ↓
Target Job
   ↓
Skill Gaps
   ↓
Career Roadmap
   ↓
Learning
   ↓
Interview Preparation
   ↓
AI Career Coach

This creates a continuous career-improvement workflow.

🌟 Project Vision
The long-term vision of Career Copilot is to become a personalized AI career companion that helps users move from:
"I don't know what to learn."

to:
"I know what my target role requires."

and then:
"I know exactly what I need to improve."

and finally:
"I have a clear roadmap to become job-ready."
