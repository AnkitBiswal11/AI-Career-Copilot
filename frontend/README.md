# Career Navigator Pro

You are a senior product designer, UX engineer, and full-stack SaaS developer.

Build a PREMIUM, PRODUCTION-QUALITY AI career platform called:

                    CAREER COPILOT

Tagline:

"Your AI-powered path from student to job-ready."

This is a serious portfolio and placement project intended to be shown to recruiters and interviewers.

DO NOT make it look like a college project.

DO NOT make it look like a generic admin dashboard.

DO NOT use a generic AI chatbot template.

The product should feel like a real startup combining:

AI + Career Intelligence + Analytics + Resume Intelligence + Job Matching + Learning Roadmaps + Interview Preparation.

============================================================

                    PRODUCT VISION

============================================================

Career Copilot helps a student answer:

1. How strong is my resume?

2. How well do I match a particular job?

3. What skills am I missing?

4. What should I learn next?

5. How ready am I for placements?

6. Which jobs should I prioritize?

7. How can I improve my resume?

8. How should I prepare for interviews?

9. What career path should I follow?

DO NOT replace it.

DO NOT create a second backend.

DO NOT move backend logic into the frontend.

The existing backend will remain responsible for:

Authentication

MySQL

Resume processing

Job descriptions

AI analysis

Ollama

Career calculations

Development backend:

http://127.0.0.1:8000

Expected API endpoints:

POST /register

POST /login

POST /resumes/upload

POST /resumes/{resume_id}/analyze

POST /jobs/

POST /jobs/{job_id}/match/{resume_id}

GET /dashboard/

Create a centralized API service layer.

Example architecture:

src/

 ├── components/

 ├── pages/

 ├── charts/

 ├── services/

 │    └── api.ts

 ├── hooks/

 ├── types/

 └── utils/

Do NOT put API calls randomly inside components.
